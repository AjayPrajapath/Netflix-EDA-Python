# 🎬 Netflix Data Analysis (Python EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Netflix dataset using Python. The goal is to understand content trends, distribution, and insights.

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset
- Netflix dataset containing information about movies and TV shows

---

## 📊 Analysis Performed
- Data cleaning and preprocessing
- Handling missing values
- Content type analysis (Movies vs TV Shows)
- Trend analysis over years
- Country-wise content distribution

---

## 🧠 Key Insights
- Movies are more than TV shows on Netflix
- Content production increased over time
- Some countries contribute more content

---

## 🖼️ Visualizations
- Bar charts for category analysis
- Trend graphs for yearly growth
- Distribution plots

---

## ▶️ How to Run
1. Open notebook in Jupyter
2. Run all cells step by step
